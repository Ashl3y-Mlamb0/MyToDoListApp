# My Todo List App

A simple todo list application built with React Native, Expo, TypeScript, and React Native Paper.

## Features

### Milestone 1
- Display todos in a list
- Beautiful UI with React Native Paper
- "Add New Todo" button (FAB)

### Milestone 2
- Navigation between screens
- Form for adding new todos
- Cancel and Save functionality

## Running the Application

1. Install dependencies:
```bash
npm install
```

2. Start the app:
```bash
npm start
```

3. Use Expo Go on your device or an emulator to run the app

## Project Structure

- `app/` - Main application code
  - `components/` - Reusable UI components
  - `screens/` - Application screens
- `assets/` - Static assets
